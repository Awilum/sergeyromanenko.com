## About this course

The course is built as theory, tests and practical tasks, and is designed for people who have never touched a database. No programming knowledge is required — only basic computer literacy and a willingness to think logically.

The free book that ships with the course repeats the material in a form you can keep as a reference, which makes the whole thing easier to revise long after you have finished.

## What you will learn

- Understand how relational databases work.
- Work with tables and records.
- Retrieve data with SELECT and choose specific columns and rows.
- Filter with WHERE and sort with ORDER BY.
- Limit output and use aggregate functions such as COUNT, SUM, AVG, MIN and MAX.
- Group data with GROUP BY and solve practical tasks on a real database.
