## About this course

SQL is a declarative language used to create, modify and manage data in relational databases. This course teaches it the way it is actually used: you read a concept, are tested on it, and then apply it against a working database.

The path runs through SELECT, filtering, sorting, grouping, joins, unions, nested queries and built-in functions, with practice between each step.

## What you will learn

- Extract information from SQL databases using queries.
- Reshape raw data into a readable form.
- Add and modify data in tables.
- Filter with WHERE and HAVING, and group with GROUP BY.
- Retrieve related data with JOIN and combine tables with UNION.
- Write nested queries and use built-in functions and expressions.
