## About this course

The program gathers the full SQL path into one enrollment: introduction, fundamentals, practical training, conditional logic, common table expressions and window functions.

Each course is theory, tests and practice against real databases, and each one is also published individually — taking the program simply gives you all of them together.

## What you will learn

1. Understand relational databases, tables and the relationships between them.
2. Write queries that retrieve, filter, sort and analyse data.
3. Use aggregate functions, grouping and conditions with WHERE, HAVING and GROUP BY.
4. Combine data from several tables with JOIN, UNION and subqueries.
5. Apply built-in functions, expressions and window functions.
6. Add, change and delete data in tables.
7. Solve practical tasks on several training databases.
