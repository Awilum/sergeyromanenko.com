## About this course

There is no theory section to hide behind. Every module puts a problem in front of you and asks for working JavaScript: read the requirements, write the solution, run the checks, fix what fails. The tasks repeat the same concepts in different forms until the language stops being something you recognise and becomes something you can produce.

The exercise set deliberately includes interview-style problems, so the course works both as everyday practice and as preparation for a JavaScript developer interview. Everything is checked automatically, which means you always know whether the solution is correct before moving on.
