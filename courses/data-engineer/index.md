A complete path to becoming a data engineer from zero: Python and Git first, then SQL from syntax to window functions, Pandas for data work, ClickHouse as the analytical database, and a first data platform built on Airflow, PostgreSQL and DataLens.

## About this course

The program is sequenced so each course feeds the next: programming fundamentals, version control, SQL, data manipulation in Pandas, an analytical database, and finally orchestration and reporting.

The end point is a finished project — from a data source through a medallion-style pipeline to a live dashboard — which is the thing an interview panel actually wants to see.

- Information Technology
- Data Analytics and Research

## What you will learn

1. Write Python programs, from basic syntax to object-oriented design.
2. Use Git and GitHub for version control and collaboration.
3. Select, join, aggregate and nest SQL queries for data engineering tasks.
4. Apply window functions and advanced analytical SQL.
5. Clean, transform and analyse data with Pandas.
6. Work with ClickHouse: its architecture, queries and storage model.
7. Build a data pipeline with Apache Airflow connected to PostgreSQL and DataLens.
8. Deliver a complete project from source to dashboard.
