## About this course

The program is sequenced so each course feeds the next: programming fundamentals, version control, SQL, data manipulation in Pandas, an analytical database, and finally orchestration and reporting.

The end point is a finished project — from a data source through a medallion-style pipeline to a live dashboard — which is the thing an interview panel actually wants to see.

- Information Technology
- Data Analytics and Research

## What you will learn

- Write Python programs, from basic syntax to object-oriented design.
- Use Git and GitHub for version control and collaboration.
- Select, join, aggregate and nest SQL queries for data engineering tasks.
- Apply window functions and advanced analytical SQL.
- Clean, transform and analyse data with Pandas.
- Work with ClickHouse: its architecture, queries and storage model.
- Build a data pipeline with Apache Airflow connected to PostgreSQL and DataLens.
- Deliver a complete project from source to dashboard.
