## About this course

SQL is the standard language for working with data held in relational databases. This course builds the fundamentals from the ground up: selecting columns and rows, filtering with WHERE, sorting, grouping with GROUP BY, joining related tables, and using built-in functions and expressions.

The material is split into theory, testing and practical parts so that each concept is read, checked and then applied. By the end you can take a plain database and answer real questions with it.

- Information Technology

## What you will learn

- Extract information from SQL databases using queries.
- Process and reshape raw data into a readable form.
- Add and modify rows and table structures.
- Filter data with WHERE and HAVING, and group it with GROUP BY.
- Retrieve related data with JOIN.
- Use built-in functions and expressions inside queries.
