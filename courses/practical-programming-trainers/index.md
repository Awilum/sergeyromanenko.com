## About this course

The program is a bundle of the individual practical trainers. Each one is a sequence of automatically checked tasks in a single language, and each one is also available separately.

Taking the bundle makes sense when you are comparing languages or working through several at once: the task formats are consistent, so moving between languages only changes the syntax.

## What you will learn

- Apply syntax from JavaScript, Go, Python, PHP, Kotlin, Java, C# and SQL to practical tasks.
- Write working programs in each language.
- Build algorithms and structured solutions to typical problems.
- Compare approaches across languages and choose the right one.
- Find and fix errors with an automatic checker.
- Optimise code and improve its efficiency.
- Learn new languages through practice.
