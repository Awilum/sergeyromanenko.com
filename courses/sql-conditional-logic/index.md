## About this course

Conditional logic is where most incorrect query results come from. This course works through three-valued logic, the behaviour of NULL, operator precedence, and how conditions behave inside grouping, sorting and aggregation.

You then apply the same ideas to conditional aggregation, data categorisation with CASE, and the mistakes that trip up experienced developers writing conditions under time pressure.

## What you will learn

1. Understand how SQL evaluates logical conditions.
2. Distinguish TRUE, FALSE and UNKNOWN, and work correctly with NULL.
3. Combine conditions with AND, OR, NOT, BETWEEN, IN and LIKE.
4. Use CASE for conditional transformation and data categorisation.
5. Apply conditional logic in SELECT, ORDER BY, GROUP BY, HAVING and UPDATE.
6. Perform conditional aggregation and write precise, predictable SQL.
