## About this course

Conditional logic is where most incorrect query results come from. This course works through three-valued logic, the behaviour of NULL, operator precedence, and how conditions behave inside grouping, sorting and aggregation.

You then apply the same ideas to conditional aggregation, data categorisation with CASE, and the mistakes that trip up experienced developers writing conditions under time pressure.

## What you will learn

- Understand how SQL evaluates logical conditions.
- Distinguish TRUE, FALSE and UNKNOWN, and work correctly with NULL.
- Combine conditions with AND, OR, NOT, BETWEEN, IN and LIKE.
- Use CASE for conditional transformation and data categorisation.
- Apply conditional logic in SELECT, ORDER BY, GROUP BY, HAVING and UPDATE.
- Perform conditional aggregation and write precise, predictable SQL.
