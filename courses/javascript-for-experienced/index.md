## About this course

This is the follow-up to the beginner course and it assumes the basics are already secure. It goes into the parts of the language that separate competent code from expert code: prototypes, classes, closures, asynchronous patterns, modules and the data structures that sit behind them.

Alongside the language itself you work through design principles, algorithms, sorting and search, and the classic problems that show up in interviews at leading companies.

- Information Technology
- Object-Oriented Programming

- Front-End Development
- Backend Development

## What you will learn

- Apply software design principles and understand the software life cycle.
- Build and analyse algorithms, including sorting and search.
- Manipulate objects, prototypes and classes using object-oriented techniques.
- Use advanced functions: anonymous, asynchronous, closures and generators.
- Work with arrays, lists, stacks, queues, trees and hash tables.
- Recognise and apply design patterns.
- Write asynchronous JavaScript with callbacks, promises and dynamic import.
- Work with JavaScript modules and build tooling.
