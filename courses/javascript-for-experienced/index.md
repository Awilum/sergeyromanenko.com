## About this course

This is the follow-up to the beginner course and it assumes the basics are already secure. It goes into the parts of the language that separate competent code from expert code: prototypes, classes, closures, asynchronous patterns, modules and the data structures that sit behind them.

Alongside the language itself you work through design principles, algorithms, sorting and search, and the classic problems that show up in interviews at leading companies.

## What you will learn

1. Apply software design principles and understand the software life cycle.
2. Build and analyse algorithms, including sorting and search.
3. Manipulate objects, prototypes and classes using object-oriented techniques.
4. Use advanced functions: anonymous, asynchronous, closures and generators.
5. Work with arrays, lists, stacks, queues, trees and hash tables.
6. Recognise and apply design patterns.
7. Write asynchronous JavaScript with callbacks, promises and dynamic import.
8. Work with JavaScript modules and build tooling.
