## About this course

The program collects the SQL path into a single enrollment: an introduction to relational databases, SQL for beginners, conditional logic, common table expressions, window functions, a practical trainer and an interview assessment. Each course assumes the one before it, so the knowledge accumulates rather than piling up.

Every course is also available separately. Taking the bundle makes sense when you want the whole route — from selecting rows to writing analytical queries — rather than a single topic in isolation.

## What you will learn

- Understand how relational databases and tables work.
- Retrieve, filter, sort and limit data with SQL queries.
- Group and aggregate results with GROUP BY and HAVING.
- Join related tables and write nested queries.
- Use conditional logic and handle NULL correctly.
- Structure complex queries with common table expressions.
- Apply window functions to analytical tasks.
- Prepare for SQL interviews and solve practical data problems.
