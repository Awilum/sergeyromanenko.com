About this course

Markdown is the markup language behind README files, documentation, forum posts, notes and a great deal of the technical writing on the web. This course covers it end to end: headings, emphasis, lists, links, images, tables, code blocks and the extended syntax that most editors support.

Every topic is followed by practice, and the accompanying free book works both as a companion to the course and as a reference you can come back to afterwards.

  • Version Control

  • Developer Tools and Software

What you will learn

  1. Write Markdown from scratch, including headings, lists, links and tables.
  2. Format code blocks and technical documentation correctly.
  3. Use extended Markdown syntax supported by modern editors.
  4. Produce polished documents, articles and README files.

Who this course is for

Suited to IT specialists, programmers, software developers, QA engineers, bloggers and content managers who write anything that ends up on a screen.

Prerequisites

None. A basic understanding of HTML is helpful later, because Markdown occasionally allows inline HTML for advanced formatting, but it is not required to start.
