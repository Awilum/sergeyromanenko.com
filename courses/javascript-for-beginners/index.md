## About this course

The course starts at the beginning and does not rush. Each concept is introduced, demonstrated and then exercised, so that by the time you reach functions, arrays and objects you have already written hundreds of small programs.

Theory, tests and practical assignments are interleaved throughout, which is why the course works both for people learning their first programming language and for developers from other languages who want a systematic JavaScript foundation.

## What you will learn

- Program in JavaScript using operators, conditions and logical expressions.
- Use control structures and data types, including type conversion.
- Create and use every common function form: named, anonymous, recursive, callback, IIFE and arrow.
- Work with arrays, sorting, filtering, multidimensional data and sets.
- Apply sorting and search algorithms, characters, substrings and regular expressions.
- Work with dates, time, maths, JSON, and handle errors with throw and try/catch.
