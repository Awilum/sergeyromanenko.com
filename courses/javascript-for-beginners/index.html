About this course

The course starts at the beginning and does not rush. Each concept is introduced, demonstrated and then exercised, so that by the time you reach functions, arrays and objects you have already written hundreds of small programs.

Theory, tests and practical assignments are interleaved throughout, which is why the course works both for people learning their first programming language and for developers from other languages who want a systematic JavaScript foundation.

  • Information Technology
  • Introduction to Programming

  • JavaScript
  • Front-End Development

What you will learn

  1. Program in JavaScript using operators, conditions and logical expressions.
  2. Use control structures and data types, including type conversion.
  3. Create and use every common function form: named, anonymous, recursive, callback, IIFE and arrow.
  4. Work with arrays, sorting, filtering, multidimensional data and sets.
  5. Apply sorting and search algorithms, characters, substrings and regular expressions.
  6. Work with dates, time, maths, JSON, and handle errors with throw and try/catch.
