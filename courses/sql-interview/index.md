## About this course

You are shown SQL statements, fragments and scenarios, and asked to determine what they do — the same format used in screening tests and technical interviews.

Because each question covers a specific topic, the course works as a map of your own SQL knowledge: the wrong answers point directly at the chapters you should revisit.
