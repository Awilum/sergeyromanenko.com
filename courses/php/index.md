## About this course

PHP still runs a very large share of the web, and this trainer is aimed squarely at people who need to write it well. Each module is a set of checked tasks rather than a set of explanations.

The problems progress from basic syntax through control flow, functions and the algorithmic questions that come up in interviews at large companies.

## What you will learn

1. Work confidently with variables, data types, control structures and functions in PHP.
2. Solve practical programming problems and find efficient solutions.
3. Prepare for a PHP developer interview, including typical task formats.
4. Build analytical thinking by solving problems of increasing difficulty.
5. Strengthen your PHP foundation and work towards a professional level.
