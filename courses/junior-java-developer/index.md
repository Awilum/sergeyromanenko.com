## About this course

This is a program rather than a single course: it bundles a sequence of courses that take you from your first Java line to a job-ready junior profile. Enrolling once gives you access to every course in the path.

Alongside the language itself you learn the tooling a working Java developer uses every day — Git and GitHub, SQL, the Linux terminal and Bash — and the Spring Framework that most Java roles expect. Interview preparation closes the path.

## What you will learn

- Write Java programs using loops, conditions and multithreading.
- Apply object-oriented programming, the Collections Framework and JUnit.
- Build applications with Spring Framework, including inversion of control and dependency injection.
- Manage versions with Git and collaborate through GitHub.
- Write and optimise SQL queries and work with transactions.
- Use the Linux command line, Bash scripts, file permissions and users.
- Prepare for a Java developer interview.
