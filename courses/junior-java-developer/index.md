## About this course

This is a program rather than a single course: it bundles a sequence of courses that take you from your first Java line to a job-ready junior profile. Enrolling once gives you access to every course in the path.

Alongside the language itself you learn the tooling a working Java developer uses every day — Git and GitHub, SQL, the Linux terminal and Bash — and the Spring Framework that most Java roles expect. Interview preparation closes the path.

## What you will learn

1. Write Java programs using loops, conditions and multithreading.
2. Apply object-oriented programming, the Collections Framework and JUnit.
3. Build applications with Spring Framework, including inversion of control and dependency injection.
4. Manage versions with Git and collaborate through GitHub.
5. Write and optimise SQL queries and work with transactions.
6. Use the Linux command line, Bash scripts, file permissions and users.
7. Prepare for a Java developer interview.
