## About this course

Instead of abstract examples, every task is set against a plausible business database: customers, orders, products, addresses, dates. You write the query, and the trainer checks the result against the expected one.

The tasks progress from straightforward selection through filtering, sorting, grouping, joins, subqueries and aggregate functions to the kind of analytical question a colleague would actually ask you.

## What you will learn

- Understand table structures and relationships in a database.
- Analyse data by writing SQL queries.
- Apply filtering, sorting and grouping to shape results.
- Build queries using JOIN, subqueries and aggregate functions.
- Solve tasks modelled on real working situations.

## Prerequisites

Basic logical and mathematical thinking and a first look at SQL. If your theory is rusty, take "SQL for Beginners" or one of the introductory courses first.
