## About this course

You work through multiple-choice questions across the whole JavaScript syllabus: syntax, types, control flow, functions, objects, arrays, asynchronous code and the language quirks that interviewers like to ask about.

Each question carries a hint and an explanation. That makes the course useful twice — once as a genuine self-assessment that shows you where the gaps are, and again as revision, because the explanation is where most of the learning happens.
