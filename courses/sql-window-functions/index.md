## About this course

Window functions let you calculate across rows that are related to the current one without collapsing the result set — running totals, rankings, moving averages, lead and lag comparisons.

The course works through OVER(), PARTITION BY, ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD and window frames with ROWS and RANGE, then applies all of it to realistic analytical tasks.

## What you will learn

1. Use window functions in SQL queries.
2. Work with the OVER() construction and partition data with PARTITION BY.
3. Use aggregate functions as window functions.
4. Compute running sums and averages.
5. Rank with ROW_NUMBER(), RANK() and DENSE_RANK().
6. Compare rows with LAG() and LEAD().
7. Control window frames with ROWS and RANGE.
