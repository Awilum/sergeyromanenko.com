## About this course

Being able to read code is a different skill from being able to write it, and it is the one you use most in a real job. This course removes the safety net: you are given a program and its expected output, and you have to work out what it does and why it does not do it.

The exercises deliberately include non-obvious and slightly obfuscated code, which is exactly what you meet in code reviews, inherited projects and interview tasks.

## What you will learn

- Read and understand unfamiliar JavaScript without comments or explanations.
- Reconstruct a program’s purpose from its inputs, outputs and behaviour.
- Analyse code logic and uncover hidden dependencies.
- Find logical errors and the causes of wrong behaviour.
- Understand what automated tests are actually asking of the code.
- Make minimal, precise fixes to an existing codebase.
- Explain how and why a program works.
