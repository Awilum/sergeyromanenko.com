## About this course

Each module is a set of tasks rather than a set of videos. You read the problem, write the solution in Python, submit it, and the automatic checker tells you whether it is right.

Because the same concepts recur across dozens of problems in different disguises, the course builds the pattern recognition that separates someone who has read about Python from someone who can actually write it.

## What you will learn

1. Work confidently with variables, data types, control structures and functions in Python.
