## About this course

The program is a bundle of the individual practical trainers. Each one is a sequence of automatically checked tasks in a single language, and each one is also available separately.

Taking the bundle makes sense when you are comparing languages or working through several at once: the task formats are consistent, so moving between languages only changes the syntax.

## What you will learn

1. Apply syntax from JavaScript, Go, Python, PHP, Kotlin, Java, C# and SQL to practical tasks.
2. Write working programs in each language.
3. Build algorithms and structured solutions to typical problems.
4. Compare approaches across languages and choose the right one.
5. Find and fix errors with an automatic checker.
6. Optimise code and improve its efficiency.
7. Learn new languages through practice.
