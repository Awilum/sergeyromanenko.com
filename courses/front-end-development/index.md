## About this course

The program sequences five courses so that each one assumes the previous: markup, styling, the JavaScript language, React, and responsive layout with Bootstrap.

Enrolling once gives you the whole path, and the final result is a set of working projects rather than a certificate of attendance.

## What you will learn

1. Write semantically correct HTML markup.
2. Style pages with CSS, including Flexbox and Grid.
3. Use JavaScript syntax, algorithms and data structures.
4. Work with JavaScript data types, functions and arrays.
5. Apply asynchronous JavaScript.
6. Use React to build single-page applications.
7. Build responsive layouts quickly with Bootstrap 5 components.
