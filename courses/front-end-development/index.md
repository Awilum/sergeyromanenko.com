## About this course

The program sequences five courses so that each one assumes the previous: markup, styling, the JavaScript language, React, and responsive layout with Bootstrap.

Enrolling once gives you the whole path, and the final result is a set of working projects rather than a certificate of attendance.

## What you will learn

- Write semantically correct HTML markup.
- Style pages with CSS, including Flexbox and Grid.
- Use JavaScript syntax, algorithms and data structures.
- Work with JavaScript data types, functions and arrays.
- Apply asynchronous JavaScript.
- Use React to build single-page applications.
- Build responsive layouts quickly with Bootstrap 5 components.
