SQL Introduction

A free beginner’s book on SQL and how relational databases actually work — readable online, downloadable as PDF or EPUB, open source on GitHub.

IT Books — PDF, EPUB, source — Russian

Read it free ↗Free to read and download. No account, no payment.

A book for people starting from zero: what SQL is, how a relational database stores and returns data, and how to write your first queries without having to guess at the syntax.

It is free, and it stays free. The whole book is on GitHub, where the source lives alongside the text, so corrections and additions are public and anyone can contribute.

Formats

The same book, in whichever form suits how you read:

  • GitHub — the source, and the place to read it online
  • PDF — for reading offline or on a phone
  • EPUB — for e-readers

Where it came from

The material is the same SQL teaching that runs in the online courses: the order in which the ideas have to arrive, and the misconceptions that have to be cleared up along the way. Writing it as a book was a way of making that sequence survive outside a single course page — so a learner who finds it years later still gets it in the right order.
