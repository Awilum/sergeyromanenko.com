# Support Independent Development

I'm an independent developer and creator building browser-based tools, educational
resources, and digital projects.

I make many of my tools freely available and aim to keep them accessible without requiring payment. If something I've created has been useful to you and you'd like to help me continue developing these projects, you can support my work using one of the options below.

Every contribution is appreciated and helps me dedicate more time to building new tools, improving existing ones, and creating useful resources.

## Payment Methods

Choose the option that works best for you. All links open in a new tab.

- **Ko-fi**
  One-time or recurring support via Ko-fi
  [Support via Ko-fi](https://ko-fi.com/sergey_romanenko)
- **PayPal**
  Secure payment via PayPal
  [Support via PayPal](https://paypal.me/sergeiromanenko)
- **YouMoney**
  Support via YouMoney
  [Support via YouMoney](https://yoomoney.ru/to/4100117657353439)
- **PayNow**
  Quick payment via PayNow
  [Support via PayNow](https://nowpayments.io/donation/sergey.romanenko)

Support is entirely voluntary. You can continue using my free tools without making a contribution.

Note: Some courses, guides, and other digital products are sold separately and are not included in this voluntary support model.
